JavaScript has no external package imports. A missing manifest is intentional: no npm install, lockfile, npm audit or npm Dependabot entry is needed. Node and Bun are the dependencies. Add explicit Node setup rather than introducing an empty package and npm dependency tree.

No Gradle, Rust, Dockerfile, Terraform, Helm or git submodule manifests exist. The only container is Actionlint; its current version and digest are verified against Docker Hub. Pre-commit hooks are a genuine missing Dependabot ecosystem.

The formerly implicit Maven lifecycle plugins resolve to clean 3.5.0, resources 3.5.0, install 3.2.0 and deploy 3.2.0 under Maven 3.10.0, as shown in the untouched-main resolution snapshot. The POM previously did not constrain these versions; it now does. Wrapper generation is a one-time maintenance operation, not a new runtime plugin. The security resolver is now explicitly pinned.
